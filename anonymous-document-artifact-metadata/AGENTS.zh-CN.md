# 匿名文档产物元数据

- 创建、编辑、转换、渲染或导出 Office、PDF、OpenDocument、带元数据图像等文档产物时，除非用户在当前任务明确要求该确切值，不嵌入或暴露姓名、组织、邮箱、账号、系统用户名等身份信息；不从登录档案、环境、本地路径、源元数据或应用默认值推断作者。
- 作者、修改者、公司、经理、评论者、审阅者等身份字段留空，必须非空时用 `Anonymous` 或 `User`。不嵌入绝对本地路径、`file://` 或泄露身份的外链/数据连接；来源用相对路径或文件名。
- 除非明确要求保留，最终导出清除继承的个人元数据和本地路径。检查实际交付二进制：OOXML 的 `docProps/core.xml`、`app.xml`、`custom.xml`、绝对路径扩展、评论/人员/作者、外链与数据连接；PDF 的信息字段和 XMP；扫描已知身份标记和主目录路径。
- 不只相信库默认值；应用保存时若重新写入身份信息，对最终产物后处理并复检。
