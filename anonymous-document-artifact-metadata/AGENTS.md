# Anonymous document artifact metadata

- When creating, editing, converting, rendering, or exporting Office, PDF, OpenDocument, metadata-bearing images, or similar artifacts, never embed or expose names, organizations, email addresses, accounts, OS usernames, home-directory names, or other identifying values unless explicitly requested for that exact value in the current task. Do not infer authorship from profiles, accounts, environment, local paths, source metadata, or application defaults.
- Leave author, creator, modifier, company, manager, commenter, reviewer, and related identity fields blank; use `Anonymous` or `User` only if non-empty text is unavoidable. Do not embed absolute local/home/temporary paths, `file://` links, or identity-revealing external links/data connections; use relative paths or source file names for provenance.
- Unless preservation is explicitly requested, scrub inherited personal metadata and local paths at final export. Inspect the delivered binary: OOXML `docProps/core.xml`, `docProps/app.xml`, `docProps/custom.xml`, absolute-path extensions, comments/people/authors, external links and data connections; PDF information fields and XMP. Scan packaged text for known identity tokens and local home paths.
- Do not rely on library defaults. If saving reintroduces identity metadata, post-process the final artifact and repeat inspection.
