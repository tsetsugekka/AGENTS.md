# Browser tab hygiene

- When using Browser Use / Computer Use to operate a browser, prefer reusing tabs suitable for the current task. Promptly close tabs opened for this task once they are no longer needed, and clear any remaining unnecessary task tabs before finishing to prevent buildup.
- Do not close the user's pre-existing tabs, tabs used by other tasks, or tabs the user asks to keep. Retain tabs needed for handoff or follow-up work and explain why. Before closing a tab, confirm that it has no unsaved content or operation that still needs to continue.
