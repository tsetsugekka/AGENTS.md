# 本地 Skill 的 API key 持久化

- 用户批准持久化的本地 Skill API key 默认存入 `${HOME}/.zshenv` 的明确托管区块；服务有更严格规范位置时从其规定。未经要求不用 Keychain 或 `launchctl`。
- 密码、key、token 优先由本机隐藏输入框或可靠的无回显交互终端接收，直接交给规定的存储/认证流程。工具无法可靠交互时，让用户在自己的终端隐藏输入或安全编辑既定文件。
- 不要求用户把凭据发到聊天或普通 shell 提示符；明文不得进入命令参数、历史、日志、工具输出、回复或 Skill 文件。只报告存在性、来源标签、权限和保存/验证结果。
